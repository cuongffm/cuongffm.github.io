Privacy Policy – Bob Uploader

Last updated: November 10, 2026 (second channel @onlyonce4000 added)

Uses YouTube API Services

Bob Uploader is a private application used only by the owner of the YouTube channels @bob_foundout and @onlyonce4000 (same owner) to upload those channels' own videos.

YouTube API Services

Bob Uploader uses YouTube API Services. By using Bob Uploader you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What data is accessed and how it is used

With the owner's consent (OAuth 2.0, scopes youtube.upload and youtube.readonly) the app uploads videos and thumbnails to the owner's own channels and reads the list and status of the owner's own uploads, only to schedule them and to avoid duplicates. It does not access, collect or process data of any other user or channel.

Storage and sharing

The OAuth token and a small log (video IDs, titles, upload times of the owner's own videos) are stored only locally on the owner's computer. No data is sent anywhere except to Google's YouTube API. No data is sold, shared or used for advertising. No cookies or tracking are used.

Data deletion and revoking access

Access can be revoked at any time at Google security settings (myaccount.google.com/permissions). Revoking access or deleting the local token file immediately stops all API access; the local log can be deleted at any time. Stored API data is refreshed or deleted within 30 days.

This app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
