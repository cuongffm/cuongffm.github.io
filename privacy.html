Privacy Policy – Bob Uploader

Last updated: November 10, 2026

Bob Uploader is a private application used only by the owner of the YouTube channel @bob_foundout to upload that channel's own videos.

What data is accessed

With the owner's consent, the app uses the YouTube Data API (scopes youtube.upload and youtube.readonly) to upload videos, set thumbnails and read the upload status of the owner's own channel. It does not access other users' accounts.

Storage

The OAuth access token is stored only locally on the owner's computer. No data is sent to any server other than Google's YouTube API. No personal data of other people is collected, stored, sold or shared.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

This app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It also uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.
